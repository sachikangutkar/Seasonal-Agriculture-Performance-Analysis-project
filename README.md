# Seasonal Agriculture Performance Analysis

## Files
- `Seasonal_Agriculture_Performance_Analysis.ipynb` – complete Jupyter Notebook
- `seasonal_agriculture_performance_cleaned.xlsx` – cleaned dataset
- `seasonal_agriculture_performance_cleaned.csv` – CSV version
- `Seasonal_Agriculture_Performance_Report.docx` – project report
- `Seasonal_Agriculture_Performance_Analysis_Presentation.pptx` – presentation
- `charts/` – result visualizations

## Dataset
The project uses the supplied `seasonal_agriculture_performance_dataset.xlsx`.

## Main Findings
- Kharif has the highest average yield and average profit.
- Zaid has the lowest average yield and negative average profit.
- Zaid has the highest average water use.
- Kharif has the highest average disease/pest risk.
- Drip irrigation has the highest average yield among irrigation methods.

## Important Note
The analysis reports associations and descriptive patterns in the supplied dataset. It does not establish causal relationships.
